# 🪙 Flip Happens

> Call your side. Blame the coin.

**Flip Happens** is a fun and interactive coin-flipping web game built with HTML, CSS, and JavaScript.

Choose **Heads** or **Tails**, flip the coin, and see if luck is on your side!

---

## ✨ Features

- 🪙 Interactive Heads & Tails coin
- 🎬 Smooth coin flipping animation
- 🏆 Win and lose animations
- 🎉 Celebration effects with confetti and popper papers
- 👥 Two-player toss mode
- 🔊 Optional sound effects
- 📊 Wins, streak and flip counter
- ↻ Quick reset button
- 📱 Mobile responsive design
- 💻 Works on desktop and mobile browsers
- 🎨 Modern glassmorphism-style interface

---

## 🎮 How to Play

### Single Player

1. Choose **Heads** or **Tails**
2. Click **FLIP IT**
3. Wait for the coin to land
4. If your choice matches the result, you win!

### Two Player Mode

1. Click **Add 2 Players**
2. Enter the names of both players
3. Choose Heads or Tails
4. Flip the coin
5. The player whose side appears wins the toss 🏆
